# NOCTURNE--THE-STATISTICAL-ARCHIVE
NOCTURNE – The Statistical Archive is a dark gothic-themed statistics calculator that simplifies calculations of mean, median, mode, standard deviation, variance, range, and quartiles. It provides step-by-step solutions, mathematical formulas, and a formula library through a multi-page interactive interface.
